    Pokémon Tags¶

    H&W keeps a few lists of Pokémon, called Pokémon tags. You can change any of them with a datapack. They're all in data/hyperspace_wormholes/tags/pokemon/:

    File What it's for
    hyperspace.json Wild Pokémon in Hyperspace
    legendaries.json Legendaries in Hyperspace
    can_feed_donut.json Pokémon you can feed a donut to

    The File¶

    Every tag file looks the same:

    {
  "replace": false,
  "values": [
    "snorlax",
    "munchlax"
  ]
}
    Key What it does
    values The list of Pokémon.
    replace false adds your Pokémon to the mod's list. true throws the mod's list away and only uses yours. Leave it out for false.

    Pokémon are written as Cobblemon's names for them, all lowercase with no spaces or dashes, like tapukoko, mrmime or farfetchd. You can also write the full id, like cobblemon:snorlax. Pokémon your Cobblemon doesn't have are just skipped.

    If more than one datapack changes the same tag, they all add up. A pack with "replace": true throws away everything from the mod and the packs loaded before it.

    Warning

    These aren't quite normal Minecraft tags. You can't put other tags (#...) in the list, and every entry has to be a plain name, not {"id": ..., "required": false}. Forms (like vulpix alolan) don't work here, so use just the species name.

    Hyperspace Spawns¶

    hyperspace.json is every wild Pokémon that can spawn in Hyperspace (866 species by default). Each trip picks 8 of them by the distortion's types and stars. You can learn more about how they're picked here.

    Only Pokémon that can walk are used, and baby Pokémon never spawn. 1 star trips use first stages, 2 star trips use middle stages and Pokémon that don't evolve, and 3 to 5 star trips use fully evolved ones. So add whole evolution lines if you want them at every star.

    This adds the Frigibax line to Hyperspace:

    {
  "replace": false,
  "values": [
    "frigibax",
    "arctibax",
    "baxcalibur"
  ]
}

    Hyperspace Legendaries¶

    legendaries.json is the legendaries that can wait on a 5 star Hyperspace trip. If one of them has the distortion's type, it gets picked. You can learn more about them here.

    Only legendaries that can walk or fly are used. Cosmog, Cosmoem, Solgaleo and Lunala are never used. With Legendary Monuments installed and its setting on Monuments, the legendaries that have a shrine are left out too.

    Anything in this tag also counts as a legendary for /hyperspace createDistortion legendary=....

    This adds Mewtwo and Rayquaza:

    {
  "replace": false,
  "values": [
    "mewtwo",
    "rayquaza"
  ]
}

    Note

    With the older wormhole colours (gameWormholeColours set to false in config/hyperspace_wormholes.json), gold wormholes use this tag too.

    Who Takes Donuts¶

    can_feed_donut.json is the Pokémon you can feed a donut to at a spatial distortion to open it, like Hoopa. By default it's only Hoopa. You can learn more about feeding donuts here.

    Use species names only, all lowercase.

    This lets Snorlax and Munchlax open distortions too:

    {
  "replace": false,
  "values": [
    "snorlax",
    "munchlax"
  ]
}
