    Boss Fights¶

    Every boss is set by a boss file. You can change Hoopa Unbound and Necrozma with a datapack, or make your own boss.

    Boss File
    Hoopa Unbound data/hyperspace_wormholes/bosses/hoopa_unbound.json
    Necrozma data/hyperspace_wormholes/bosses/necrozma_megalopolis.json
    Your own data/<namespace>/bosses/<id>.json

    Your file replaces the mod's whole file, so copy the mod's one and change what you want. Every key can be left out. Anything you leave out uses its default.

    You can learn more about how boss fights work here.

    Your Own Boss¶

    A new boss file doesn't show up in the world by itself. An operator spawns it with /boss spawn <id>, for example /boss spawn mypack:mewtwo. Bosses in the hyperspace_wormholes namespace only need the id, like /boss spawn hoopa_unbound.

    It stays where it was spawned. Players join the fight by starting a battle with it like a wild Pokémon. Once it's beaten, everyone still in the fight can throw a Poké Ball in their own battle to catch their own copy of it.

    Main Keys¶

    Key What it does Default
    name The name on the boss's HP bar. Plain text or a translation key. The species name
    spawn_species The species /boss spawn makes it from. It goes in front of properties. None
    properties The boss Pokémon, written like Cobblemon's /pokespawn (species, level, form and so on). None
    moves Up to 6 moves it uses in the fight, instead of its own. Its own moves
    hp_per_trainer Its HP is its normal max HP times this, times the number of players. 5
    scaling A list of HP multipliers for 1, 2, 3 and 4 players, used instead of hp_per_trainer. With more players than entries, the last one is used. None
    max_trainers How many players can fight it at once. 4
    scale Its size. 1 is normal size. 1.5 with /boss spawn, 1 for Hoopa and Necrozma
    ai_skill How smart it battles, up to 5 (smartest). 5
    boosts Stat stages it gets at the start of the fight. See Boosts. None
    music Its battle music, as a sound event id. Cobblemon's normal battle music
    ultimate A big move it uses once at low HP. See Ultimate. None
    forms Form changes at HP marks. See Forms. None
    variants Named versions of the boss, each with its own name, properties, moves and music. See Variants. None
    defeated_properties Cobblemon properties put on it once it's beaten, so the one you catch can be different. None
    banned_moves Moves players' Pokémon can't use against it. Your list replaces the default one, and [] bans nothing. The 13 moves here
    opening_transition_seconds Hoopa and Necrozma only. How long the screen transition before the fight lasts. The music starts with it. 0

    Moves, abilities and items are written in lowercase with no spaces, like darkpulse or megaloneuroforce.

    The defaults for hp_per_trainer, max_trainers, scale and ai_skill come from config/hyperspace_wormholes_boss.json, so a server can change them for every boss that doesn't set its own.

    Boosts¶

    boosts is a list of stats and how many stages each one goes up (or down, with a minus number):

    "boosts": {"highest": 1, "spe": 1}

    The stats are atk, def, spa, spd, spe, accuracy and evasion. highest is whichever of its stats is highest. In hard mode, highest goes to every stat instead.

    Ultimate¶

    The ultimate is a move it uses once when its HP drops below a mark. It hits every player's Pokémon at once.

    "ultimate": {"move": "photongeyser", "zmove": true, "hp_below": 0.33, "hard_again_below": 0.11}
    Key What it does Default
    move The move. You need this one. None
    zmove true uses it as that move's Z-Move. It needs a Z-Crystal for that, see z_item below. false
    hp_below It's used when its HP drops below this much of its max. 0.33 is 33%. 0.33
    hard_again_below In hard mode, it's used a second time below this mark. 0 turns that off. 0

    Forms¶

    forms is a list of form changes. Each one happens once its HP drops below its hp_below mark. Its HP stays at the same percent when it changes. A form only needs the keys it changes.

    Key What it does Default
    hp_below It changes when its HP drops below this much of its max. 0.5 is 50%. 0.5
    name A new name for the HP bar. Keeps the old one
    properties Cobblemon properties put on it, which changes how it looks. None
    species The species it battles as, written the way Pokémon Showdown does, like Necrozma-Ultra. No change
    level A new level. No change
    ability A new ability. No change
    item The item it battles with. No change
    held_item An item id it really holds, like mega_showdown:ultranecrozium_z. No change
    z_item A Z-Crystal it counts as holding for Z-Moves only, so its real held item stays. None
    moves New moves, up to 6. No change
    boosts Stat stages it gets when it changes. None
    music New battle music. No change
    ultimate Its own ultimate, used instead of the main one. The main one

    Note

    In Hoopa's fight, the first two forms are only used for the HP marks where it calls in legendaries (80% and 40% by default). Their other keys don't do anything there, and which legendaries come out can't be changed.

    Variants¶

    variants is how Necrozma comes as Dusk Mane or Dawn Wings. Its fight flips a coin between the dusk and dawn variants, so keep those two names in Necrozma's file. /boss spawn picks a variant at random too, but only uses its properties.

    "variants": {
  "dusk": {
    "name": "Dusk Mane Necrozma",
    "properties": "prism_fusion=dusk moves=sunsteelstrike,photongeyser,earthquake,dragondance",
    "moves": ["sunsteelstrike", "photongeyser", "earthquake", "dragondance", "stoneedge", "knockoff"]
  },
  "dawn": {
    "name": "Dawn Wings Necrozma",
    "properties": "prism_fusion=dawn moves=moongeistbeam,photongeyser,powergem,calmmind",
    "moves": ["moongeistbeam", "photongeyser", "powergem", "calmmind", "earthpower", "heatwave"]
  }
}

    Necrozma Only¶

    These only do something in the Necrozma fight. Ticks are 1/20 of a second.

    Key What it does Default
    power_up_ticks How long the Ultra Burst scene lasts. 80
    defeat_ticks How long the defeat scene lasts. 240
    defeat_form_ticks When in the defeat scene defeated_properties go on. Same as defeat_ticks
    defeat_effect A Mega Showdown effect played in the defeat scene: id (the effect), at (the tick it starts on) and aspects (what it changes). None

    Warning

    The scene timings are made to match Necrozma's animations and music. If you change them, the scenes can cut off early or hang.

    Server Config Overrides¶

    Server owners can also change single keys without a datapack. Put a file in config/hyperspace_wormholes/bosses/ named after the boss, like hoopa_unbound.json (or mypack__mewtwo.json for another namespace). Only the keys in it change, and they win over datapacks.

    {"max_trainers": 2}

    Example¶

    This is a Mewtwo boss that gets faster and stronger at half HP.

    data/mypack/bosses/mewtwo.json:

    {
  "name": "Mewtwo",
  "properties": "mewtwo level=80",
  "moves": ["psystrike", "aurasphere", "icebeam", "flamethrower", "calmmind", "recover"],
  "scaling": [8, 16, 24, 32],
  "scale": 1.5,
  "boosts": {"highest": 1},
  "ultimate": {"move": "psystrike", "hp_below": 0.25},
  "forms": [
    {
      "hp_below": 0.5,
      "name": "Enraged Mewtwo",
      "moves": ["psystrike", "aurasphere", "thunderbolt", "shadowball", "nastyplot", "recover"],
      "boosts": {"spe": 1, "spa": 1}
    }
  ],
  "defeated_properties": "level=70"
}

    Run /reload, then spawn it with /boss spawn mypack:mewtwo.
